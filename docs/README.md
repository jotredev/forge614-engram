Bienvenido a la documentación oficial de **Forge614 Engram**, un sistema de memoria personal y local para modelos de inteligencia artificial y aplicaciones de software estructurado internamente como un **monolito modular organizado por funcionalidad** (separando reglas puras de dominio, coordinación de aplicación, adaptadores de infraestructura e interfaces de terminal/asistente). En su versión **1.1.0**, Engram reside en su propio hogar de producto aislado (`~/.forge614/engram/` con binario en `~/.forge614/engram/bin/`), conviviendo armónicamente dentro del contenedor familiar `~/.forge614/` junto a productos hermanos como Forge614 Shell y Forge614 Atlas sin invadir ni alterar sus carpetas. Incorpora migración segura y automática de instalaciones anteriores, un comando de desinstalación protegida (`uninstall`) coordinado con Atlas, inicialización mediante `forge614-engram init` (modo interactivo guiado o headless no interactivo `init --json` para automatización y CI/CD), retiro formal del antiguo comando `setup` (`COMMAND_RETIRED`), total independencia operativa respecto a Shell en tiempo de ejecución (Shell es el onboarding visual opcional recomendado, pero los asistentes de IA conectan directamente con Engram vía stdio MCP sin requerir que Shell esté abierto), un **Centro de Control TUI interactivo en terminal** (`forge614-engram tui`) con navegación de sólo lectura y confirmación estricta de dos pasos (`confirm` + Enter), búsqueda explicable reforzada por repeticiones [sin embeddings](es/conceptos/que-son-los-embeddings.md) (SQLite FTS5 trigram con factores matemáticos de actualidad y estabilidad), servidor MCP nativo por stdio con 10 herramientas de memoria, sesiones progresivas (`timeline`), contexto clasificado (`context`), API pública en TypeScript de inspección para Atlas, contrato no visual de inicialización para Forge614 Shell (`inspectMemoryInitialization`, `previewMemoryInitialization`, `applyMemoryInitialization`), y sincronización opcional directa con PostgreSQL Formato 3.

Welcome to the official documentation for **Forge614 Engram**, a personal local memory system for artificial intelligence models and software applications structured internally as a **feature-oriented modular monolith** (separating pure domain rules, application orchestration, infrastructure adapters, and terminal/assistant interfaces). In release **1.1.0**, Engram resides in its own isolated product home (`~/.forge614/engram/` with its binary in `~/.forge614/engram/bin/`), coexisting seamlessly within the shared family container `~/.forge614/` alongside sibling products such as Forge614 Shell and Forge614 Atlas without touching their workspaces. It incorporates automatic safe migration from legacy installations, a guarded multi-product uninstaller (`uninstall`) coordinated with Atlas, initialization via `forge614-engram init` (guided interactive mode or headless non-interactive `init --json` for automation and CI/CD), permanent retirement of legacy `setup` (`COMMAND_RETIRED`), full runtime operational independence from Shell (Shell serves as the recommended optional visual onboarding, but connected AI clients talk directly to Engram via stdio MCP without requiring Shell to run or stay open), an interactive **Terminal Control Center (TUI)** (`forge614-engram tui`) featuring safe read-only navigation and two-step action confirmation (`confirm` + Enter), explainable search reinforced by repetitions [without embeddings](en/concepts/what-are-embeddings.md) (local SQLite FTS5 trigram with mathematical recency/stability multipliers), a native stdio MCP server featuring 10 memory tools, progressive memory sessions with session timelines (`timeline`), ranked assembled prompt context (`context`), a public TypeScript assistant inspection API for Atlas, a nonvisual initialization contract for Forge614 Shell (`inspectMemoryInitialization`, `previewMemoryInitialization`, `applyMemoryInitialization`), and optional direct synchronization with PostgreSQL Format 3.
